# Repository instructions

## Implementation journal

Maintain `JOURNAL.md` for every material change made in this repository.

- Add the newest entry immediately below the journal title, so entries are in reverse chronological order.
- Use this heading format exactly: `## YYYY-MM-DD HH:MM - <what>`.
- Under each heading, state concisely what changed, why it changed, and how it was tested. If no test was run, say so explicitly and explain why.
- Record only non-sensitive summaries; never add credentials, private data, or actual period records.
- Update the journal before handing work back to the user.
